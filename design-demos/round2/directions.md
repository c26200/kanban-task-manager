# Kanban Flow — Ronda 2

## Spec

Tablero kanban de tres columnas con drag and drop, edición en línea y persistencia local.
Contenido real: To Do (2), In Progress (2), Done (1); tareas: Analyze competitors; Design
high-fidelity wireframes; Set up the database (Supabase); Implement authentication; Create
the GitHub repository. Formato 1440×900. Cuerpo ≥14 px, etiquetas ≥12 px, contraste ≥4.5:1.

**Lo que se descartó en la ronda 1:** navy editorial con rail, franjas estacionales y gris
funcional. Nada de eso se repite aquí.

---

## Candidatos

### 1 · Best designer — Otl Aicher
- **Lógica.** Sistemas de señalización y dibujo técnico: retícula visible, anotaciones,
  líneas de cota, azul de plano.
- **Qué se toma.** Papel cuadriculado, tinta azul, mono para medidas, zonas con borde
  discontinuo.
- **Esqueleto.** Plano: tres zonas acotadas, tarjetas como piezas anotadas.
- **Audacia.** El tablero se lee como un plano de ingeniería.
- **Form.** Un tablero es un plan de trabajo; mostrarlo como plano es honesto.

### 2 · Best designer — Herbert Bayer (Bauhaus)
- **Lógica.** Geometría primaria: círculo, cuadrado, triángulo; rojo, azul, amarillo; negro.
- **Qué se toma.** Formas grandes de color tras cada estado, tipografía geométrica, bordes
  negros.
- **Esqueleto.** Tres columnas, cada una con una forma primaria y su color.
- **Audacia.** El color y la forma identifican el estado antes que el texto.
- **Form.** Tres estados son tres formas: se distinguen sin leer.

### 3 · Best designer — Irma Boom (fichero)
- **Lógica.** El fichero de biblioteca: fichas de cartulina, pestañas, sellos de goma,
  máquina de escribir.
- **Qué se toma.** Fichas con renglones, pestañas de sección, sellos rojos, mono de máquina.
- **Esqueleto.** Cajón de fichero: tres secciones con pestañas y fichas.
- **Audacia.** Cada tarea es una ficha física con sello de estado.
- **Form.** Una tarea es una ficha que se mueve de cajón.

### 4 · Referencia real — Linear
- **Lógica.** Herramienta oscura y precisa: densidad, violeta, hairlines.
- **Esqueleto.** Rail + columnas densas.
- **Audacia.** Densidad sin ruido.

### 5 · Referencia real — Trello
- **Lógica.** El kanban de referencia: tablero azul, listas claras, tarjetas.
- **Esqueleto.** Fondo azul + tres listas.
- **Audacia.** El color del tablero como identidad.

### 6 · Ruleta — east #12 POPEYE / revista densa
- **Lógica.** Papel, retícula densa, titulares con subrayado, anotaciones, celdas numeradas.
- **Esqueleto.** Portada de revista con sumario y fichas.
